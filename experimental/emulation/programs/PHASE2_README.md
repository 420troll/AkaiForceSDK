# Original ES5510 Phase 2 programs

These are original TROLLfx microprograms. They are not recovered Ensoniq
firmware, factory effects, or claims of DP/4 compatibility. Both execute their
delay, MAC, feedback/mix and serial I/O work through the standalone ES5510
instruction engine.

## Build the bundles

```sh
python3 tools/es5510_asm.py delay experimental/emulation/programs/original_stereo_feedback_delay.esp \
  --sample-rate 44100 --delay-ms 250 --max-delay-ms 10000 --feedback 0.55
python3 tools/es5510_asm.py chorus experimental/emulation/programs/original_stereo_chorus.esp \
  --sample-rate 44100 --delay-ms 25 --max-delay-ms 10000 --depth-ms 5 --rate-hz 0.5 --wet 0.5
```

The assembler supports the checked-in `MOV`, in-place `ADD`, register and
DIL MAC, DOL write, and END forms. The checked-in `_48k` bundle variants use
48 kHz delay offsets; the default bundles use 44.1 kHz. It emits the `ES5510_BUNDLE 1` format used
by the headless renderer. The delay runs 19 words/frame; the chorus runs 11 words/frame.

The bundles set `MEMSIZ` (special register 244) to zero: the ES5510 then uses
one raw offset unit per 16-bit DRAM word. `DLength` is `ring_samples-1`; END
moves DBASE backward by one sample each audio frame. Each stereo program uses
a 2-bank ring (`2 * max-delay-samples`) with the right bank offset by the
per-channel capacity. At 44.1 and 48 kHz, the default 10-second per-channel
capacity uses 882,000 or 960,000 words, within the standalone engine's 1M-word
DRAM. Higher sample rates may require a shorter maximum; the assembler rejects
rings larger than 1M words.

Non-MAC instructions set unused C and D fields to GPR 255, a non-writable
constant register. Every instruction also executes the MAC in parallel, so
leaving those fields at zero would cause unintended GPR0 writeback. END uses
MAME's all-ones unused register fields to keep the delayed pipeline from
writing GPR0 when the next frame restarts at PC 0.

## Delay behavior

`stereo_feedback_delay.asm` reads the prior left/right delay cells at PC 0/1,
multiplies DIL by the Q22 feedback coefficient in GPR 40 at PC 2/3, adds the
returns to copies of the dry inputs, and writes the loop sums to the delay
banks. Separate MAC passes scale the delayed and dry signals for output. The
feedback loop is `input + feedback * delayed`. Output is independently
`dry_gain * input + wet_gain * delayed`, with three distinct Q22 coefficients
in GPRs 40 (feedback), 41 (wet), and 42 (dry). `--feedback` is limited to
0–0.94; `--wet` and `--dry` each range from 0–1. Their sum can exceed unity,
so high settings may clip. The default 250 ms / 0.55 feedback / 50% wet / 50%
dry preset produces stable repeated echoes without clipping on the checked-in
impulse or chord.

## Chorus behavior

`stereo_chorus.asm` writes dry input to the two banks and outputs
`dry + wet * delayed` with the wet gain in GPR 40. Its delay reads are at PC 0
(left) and PC 1 (right). `lfo_gpr` bundle records provide host-computed sine
modulation before each frame:

- GPR 0: left read offset; base 1,102 samples, depth 220 samples, 0.5 Hz,
  phase 0 cycles, clamp 882..1,322.
- GPR 1: right read offset; base 442,102 (right bank plus 1,102), depth 220,
  0.5 Hz, phase 0.5 cycles, clamp 441,882..442,322.

Offsets use raw ES5510 delay-address units (one unit/sample with MEMSIZ 0).
The two LFOs are opposite phase. Delay storage and wet/dry arithmetic still
run as ES5510 instructions; only the modulation trajectory is generated by
the host/renderer. The default 25 ms base, 5 ms depth, 0.5 Hz rate and 50% wet
mix produce repeatable movement. This is not a self-running ESP LFO program.

## Reproducible audio examples

`artifacts/es5510-emulation/phase2/` contains the final delay and chorus
impulse and musical-input renders. `phase2/wetdry/` mirrors the final 19-word
delay WAVs used for wet/dry control isolation. Musical input is the existing
three-second synthetic chord. Render again with:

```sh
/tmp/es5510-render experimental/emulation/programs/original_stereo_feedback_delay.esp \
  artifacts/es5510-emulation/original_test_chord_input.wav /tmp/delay.wav
/tmp/es5510-render experimental/emulation/programs/original_stereo_chorus.esp \
  artifacts/es5510-emulation/original_test_chord_input.wav /tmp/chorus.wav
```

For the wet/dry feedback-delay impulse, dry output is half-level at frame 0;
wet echoes repeat at frames 11,025, 22,050, 33,075, etc. With 0.55 feedback,
the first wet echo is half-level and each following echo is 0.55 times the
previous. Wet=0 removes delayed output; dry=0 removes direct output. These
settings affect separate MAC operations. Control-isolation renders confirm
wet=0 removes all echoes, dry=0 removes the frame-zero direct sample, and
feedback 0.25 versus 0.75 changes the second echo from 3,072 to 9,216 counts
on the left while leaving the first echo equal. The default 4-second impulse
output and 3-second chord output are in
`artifacts/es5510-emulation/phase2/`.

For the default chorus impulse, modulated echoes begin near 1,120 frames left
and 1,085 frames right (opposite phases). The default chorus has 25 ms nominal
delay and 5 ms LFO depth; the impulse first wet returns are approximately
25.4 ms left and 24.6 ms right. The LFO result differs from a fixed-offset chorus on
the same chord input (normalized output difference 0.5895); rendering the same
bundle twice is sample-identical.
