# ESP Lab skin milestone

The V0.2 SDK skin now uses a warm amber/copper accent on a charcoal background,
with high contrast labels and the official SDK's large 4-by-4 control grid.
The asset kit is generated by the SDK and contains abstract controls only; it
uses no Ensoniq logo, product photo, or trademark artwork.

Tabs: ROUTING, UNIT A, UNIT B, UNIT C, UNIT D, and MODULATE (the SDK truncates
tab names beyond eight characters; the page heading reads “MODULATION / RATE +
DEPTH”). Unit pages expose algorithm, time, depth, rate, feedback, bypass and
mix. The modulation page duplicates the four units' actual Rate and Depth
parameters for quick access. Routing shows mode, active unit, and per-unit
algorithm/bypass/mix so the active chain can be selected and read without
inventing a static path diagram that could misrepresent Parallel or Dual mode.
Each page has its own generated Q-Link parameter map; controls occupy the SDK's
standard 1280x800 host canvas and Q-Link focus groups.

Validation: official SDK build `tools/build.py plugins/TROLLfxESPLabV02
--target all --toolchain zig --zig /usr/bin/python3` completed native,
ARM32/Cortex-A17, and ARM64 outputs; SDK validation reported 0 errors and 0
warnings. UI generator reported a long tab label warning before its label was
shortened to `MODULATE`; run the command again to regenerate final assets.
Touchscreen appearance still requires a permitted Force hardware review.
