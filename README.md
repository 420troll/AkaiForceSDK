# TROLLfx Force SDK

Research and implementation workspace for Ensoniq-inspired real-time DSP on the
original 32-bit ARMv7 Akai Force.

Start with [`docs/HANDOFF_001.md`](docs/HANDOFF_001.md) and
[`docs/RESEARCH_INDEX.md`](docs/RESEARCH_INDEX.md). This repository contains no
Ensoniq ROM, firmware, factory microcode, or effect binaries.

Status: research baseline only. No TROLLfx algorithm implementation has yet
been claimed as an exact recovery of an Ensoniq algorithm.
