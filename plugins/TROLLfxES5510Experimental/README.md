# TROLLfx ES5510 Experimental VST V0.1

A stereo Akai VST2 effect embedding the standalone MAME-derived ES5510 processor
and original TROLLfx microprograms. DELAY runs the 19-word stereo feedback
program; CHORUS runs the 11-word stereo chorus program with host-computed,
opposite-phase GPR delay offsets. The audio effects themselves execute as
ES5510 instructions. These are original TROLLfx programs, not recovered
Ensoniq factory algorithms.

See `INSTALL.txt` for Force installation and SSD mount inspection instructions.
See the repository's `experimental/emulation/THIRD_PARTY_NOTICES.md` for the
MAME BSD-3-Clause notice, reproduced in the package.
