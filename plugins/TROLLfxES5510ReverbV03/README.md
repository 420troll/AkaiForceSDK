# TROLLfx ES5510 V0.3 — Nonlinear & Reverb Lab

Single consolidated stereo Force VST2 plugin (host name `ES5510 NonLin Reverb V0.3`), UID `Tfx3`. Includes the
ES5510 delay, tempo delay, chorus, phaser, panner, ping-pong and rotary
algorithms alongside original TROLLfx ES5510 NonLin 1/2/3, plate, room, hall,
gated and reverse reverb programs. NonLin tap levels are independent controls;
HF damping executes as an ES5510 one-pole filter in the plate/room/hall and
gate/reverse programs.
Factory DP/4 firmware and effect microcode are not included; these are
independent implementations guided by documented behavior and exposed controls.

The older V0.1/V0.2 plugin projects are not runtime dependencies. V0.3 installs
in a separate folder for hardware verification. Safe archive commands for the
older Force folders are provided in the V0.3 handoff; run them only after
verifying V0.3 on hardware.
